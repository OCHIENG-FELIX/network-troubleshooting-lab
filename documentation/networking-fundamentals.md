# Networking Fundamentals

## Overview
Computer networking allows devices to communicate and share resources over wired or wireless connections.

## Key Networking Concepts

### 1. IP Address
An IP address identifies a device on a network. IPv4 addresses consist of four octets, for example `192.168.1.10`.

### 2. Subnet Mask
A subnet mask identifies the network and host portions of an IP address. A common example is `255.255.255.0`.

### 3. Default Gateway
A default gateway allows a device to communicate with destinations outside its local network. It is commonly the address of a router.

### 4. DNS
Domain Name System translates domain names into IP addresses so devices can locate internet services.

### 5. DHCP
Dynamic Host Configuration Protocol automatically assigns network configuration details, including IP addresses, to devices.

### 6. MAC Address
A Media Access Control address is a hardware identifier associated with a network interface.

## Types of Networks
- LAN: Local Area Network.
- WAN: Wide Area Network.
- WLAN: Wireless Local Area Network.

## Common Network Problems
- No internet connectivity.
- Incorrect IP configuration.
- DNS resolution failures.
- Weak Wi-Fi signals.
- Network adapter problems.
- Intermittent connectivity.

## Practical Relevance
Understanding these concepts helps IT support technicians identify connectivity problems and determine whether the issue involves the device, local network, or external network.
