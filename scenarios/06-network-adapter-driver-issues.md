# Scenario 6: Network Adapter and Driver Issues

## Problem Description
A computer cannot connect to a network because its network adapter may be disabled, malfunctioning, or affected by a driver issue.

## Symptoms
- Wi-Fi option missing.
- Ethernet adapter unavailable.
- Device Manager reports an error.
- Network connection fails after a driver update.

## Possible Causes
- Disabled network adapter.
- Missing or corrupted driver.
- Incompatible driver update.
- Hardware failure.
- Operating system configuration issue.

## Diagnostic Procedure

1. Open Device Manager using `devmgmt.msc`.
2. Expand Network adapters.
3. Inspect the adapter status.
4. Check for warning symbols or error codes.
5. Review recent driver changes.
6. Check adapter status in Windows network settings.

## Possible Resolutions
- Enable a disabled adapter.
- Install an approved driver from the device manufacturer.
- Roll back a problematic driver when appropriate.
- Reinstall the driver if justified.
- Escalate suspected hardware faults.

## Verification
- Confirm the adapter appears correctly in Device Manager.
- Confirm the network interface is enabled.
- Test wired or wireless connectivity.
- Verify normal network access.
