# Scenario 5: Intermittent Network Connection

## Problem Description
A user reports that their network connection repeatedly disconnects and reconnects.

## Symptoms
- Websites load inconsistently.
- Video calls disconnect.
- Network connection drops periodically.
- Applications experience timeouts.

## Possible Causes
- Weak Wi-Fi signal.
- Wireless interference.
- Damaged Ethernet cable.
- Network adapter driver problems.
- Router or access-point instability.
- Network congestion.

## Diagnostic Procedure

1. Establish how frequently the problem occurs.
2. Determine whether the device uses Wi-Fi or Ethernet.
3. Check signal strength for wireless connections.
4. Inspect cables and network ports.
5. Run repeated gateway ping tests.
6. Compare results with another device on the same network.
7. Review adapter status and relevant Windows events.

## Possible Resolutions
- Improve Wi-Fi signal strength.
- Replace damaged cables.
- Update or reinstall appropriate drivers.
- Investigate router or access-point issues.
- Escalate persistent infrastructure problems.

## Verification
- Monitor connectivity over an appropriate period.
- Test applications affected by the problem.
- Confirm stability with the user.
