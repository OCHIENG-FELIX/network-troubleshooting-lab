# Network Configuration Checklist

## Network Interface
- [ ] Confirm the correct network adapter is installed.
- [ ] Confirm the adapter is enabled.
- [ ] Inspect cable or wireless connection.
- [ ] Check adapter driver status.

## IP Configuration
- [ ] Verify the IPv4 address.
- [ ] Verify the subnet mask.
- [ ] Verify the default gateway.
- [ ] Verify DNS server settings.
- [ ] Confirm DHCP or approved static configuration.
- [ ] Check for IP address conflicts.

## Connectivity
- [ ] Confirm local network connectivity.
- [ ] Test gateway communication.
- [ ] Test external IP connectivity.
- [ ] Verify DNS resolution.
- [ ] Check route information when necessary.

## Security and Documentation
- [ ] Do not expose network credentials.
- [ ] Follow organizational network policies.
- [ ] Obtain authorization for configuration changes.
- [ ] Record the original configuration before changes.
- [ ] Document the final configuration.
- [ ] Escalate suspected infrastructure problems.
