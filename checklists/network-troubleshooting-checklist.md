# Network Troubleshooting Checklist

## 1. User Information
- [ ] Record the user's name or ticket reference.
- [ ] Record the affected computer or device.
- [ ] Identify when the issue started.
- [ ] Record the exact error message.
- [ ] Establish the impact and urgency.

## 2. Initial Checks
- [ ] Check Wi-Fi or Ethernet connection.
- [ ] Confirm airplane mode is disabled.
- [ ] Check cables and network ports.
- [ ] Determine whether other devices are affected.
- [ ] Identify whether the issue affects one application or all network access.

## 3. Network Configuration
- [ ] Run `ipconfig /all`.
- [ ] Check IP address.
- [ ] Check subnet mask.
- [ ] Check default gateway.
- [ ] Check DNS servers.
- [ ] Check DHCP status.

## 4. Connectivity Tests
- [ ] Test loopback using `ping 127.0.0.1`.
- [ ] Test the default gateway.
- [ ] Test an external IP address where appropriate.
- [ ] Test DNS using `nslookup`.
- [ ] Investigate the route using `tracert` if necessary.

## 5. Resolution
- [ ] Identify the likely cause.
- [ ] Test one change at a time.
- [ ] Obtain authorization before configuration changes.
- [ ] Escalate issues outside the support technician's authority.
- [ ] Record actions taken.

## 6. Verification and Closure
- [ ] Confirm connectivity has been restored.
- [ ] Test the affected applications.
- [ ] Confirm with the user.
- [ ] Document the resolution.
- [ ] Record preventive recommendations.
