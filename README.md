# Network Troubleshooting Lab

## Project Overview
This project documents common computer networking issues and demonstrates structured troubleshooting methods used in IT support environments.

It focuses on identifying network connectivity problems, investigating their possible causes, applying appropriate diagnostic tools, and documenting recommended resolutions.

## Project Objectives
- Understand fundamental networking concepts.
- Troubleshoot common network connectivity problems.
- Interpret IP addressing, subnet masks, default gateways, and DNS settings.
- Use Windows command-line networking tools.
- Identify possible DHCP, DNS, and network adapter issues.
- Apply a systematic troubleshooting methodology.
- Document findings, resolutions, and verification steps.

## Environment
- Operating System: Windows 11
- Platform: Personal computer / network troubleshooting lab
- Tools: Command Prompt, Windows Network Settings, Network and Sharing Center, Device Manager
- Additional tools: `ipconfig`, `ping`, `tracert`, `nslookup`

## Project Structure
The project will contain:

- `documentation/` – Networking concepts and diagnostic procedures.
- `scenarios/` – Common network troubleshooting cases.
- `checklists/` – Network troubleshooting and configuration checklists.

## Planned Troubleshooting Scenarios
1. No internet connectivity.
2. DNS resolution failure.
3. Incorrect IP configuration.
4. Default gateway connectivity problems.
5. Intermittent network connection.
6. Network adapter and driver problems.

## Troubleshooting Methodology
Each scenario follows a structured process:

1. Identify the reported problem.
2. Gather information and establish the scope.
3. Inspect the network configuration.
4. Identify possible causes.
5. Test potential solutions systematically.
6. Apply an appropriate resolution.
7. Verify network connectivity.
8. Document findings and recommendations.

## Skills Demonstrated
- Network troubleshooting
- TCP/IP fundamentals
- IP configuration analysis
- DNS and DHCP fundamentals
- Default gateway troubleshooting
- Windows network diagnostics
- Problem-solving and technical documentation
